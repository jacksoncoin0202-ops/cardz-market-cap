## 三、「點樣做得更好」建議

> 以下係建議，**未郁代碼**。按「剋制」原則排優先。

1. **Delta 箭嘴 animation 改一次性或移除**（對應 #1）
   保留 `transition: color 0.17s` 就夠，唔使 400 個 SVG 無限郁。若要動感，改 `animation-iteration-count: 1` 或 hover 先觸發。呢個係全站最大嘅「唔剋制」位。

2. **Accent 橙 dark mode 調亮**（對應 #2）
   `rgb(232,130,63)` 調亮至對比 ≥ 4.5（例如 `rgb(255,150,80)`），或加 `text-shadow`。

3. **觸控目標統一 44px**（對應 #3）
   Header 按鈕、Grader Tab、Share card 加 `min-height: 44px`；Slider 加垂直 padding 擴大點擊區。

4. **Mobile H1 統一 36px**（對應 #4）
   三個頁面 H1 統一 `font-size: 36px; line-height: 1.1`。

5. **Heatmap tile 陰影減弱**（對應 #5）
   `box-shadow: 0 1px 4px rgba(8,8,8,0.1)` 或移除，改用幼 border。

6. **卡圖去白框**（對應 #6）
   移除 `inset 0 0 0 2px rgba(255,255,255,…)`，保留圓角 + 柔和陰影。

7. **Donut chart 用色同 heatmap 統一**（對應 #7）
   PSA 改用全站 accent 橙或綠，避免同跌色撞。

8. **Slider 加文字 label**（對應 #8）
   `顯示格數 [range] 100`，語義清晰。

9. **圓角統一 8px**（對應 #9）
   全站卡片、tile、表格統一 `border-radius: 8px`。
