## 3. 點樣運用

### 3.1 五分鐘日常：開 `card_metrics.csv`

Excel / Google Sheets 直接開，每行一隻卡：

| 欄位 | 意思 | 用法 |
|------|------|------|
| `latestPrice` | 最新成交價（PSA 10 序列） | 而家值幾錢 |
| `change1dPct` / `change7dPct` / `change30dPct` | 升跌% | 搵異動：|7d| > 20% 值得睇 |
| `volume7d` / `volume7dUsd` | 7 日成交筆數 / 美元額 | 流動性：高成交額先走得甩 |
| `seriesGrade` / `seriesSaleCount` | 升跌% 基於邊條序列 | 樣本 <10 嘅升跌% 當參考好啲 |
| `indexPriceUsd` / `indexChange30dPct` | G10 官方指數口徑 | 同你自己計嘅對照 |

實用篩選例子：
- **異動掃描**：`|change7dPct| >= 20` 並且 `volume7dUsd >= 5000`（郁得勁又有成交支持）
- **放量下跌**：`change7dPct < -15` 並且 `volume7d` 高於該卡平常 → 可能係接貨機會或崩盤開端，配合 K 線睇
- **流動性排名**：`volume30dUsd` 排序 — 頭 50 隻先係「走得甩」嘅貨

### 3.2 K 線點睇（`data/analytics/klines/`）

每卡一個 CSV，一行一日：

```
date,       open,    high,    low,     close,   tx,  volumeUsd,  carried
2026-07-21, 5834.99, 5834.99, 5834.99, 5834.99, 0,   0,         1
2026-07-22, 2677.45, 6838.95, 2677.45, 6838.95, 87,  204240,     0
```

- `carried=1`：該日無成交，收盤價係前一日帶過嚟（平線）。**唔係假數據，係「無交易」嘅標記**，畫圖時可以選擇顯示或斷開。
- `tx` / `volumeUsd`：該日**所有等級、所有平台**嘅成交（量係全量，價係 PSA 10）。
- 直接入 TradingView 輕量圖表庫、Excel 股價圖、或 Python plotly 都得。

**而家嘅階段性特徵**（好緊要，唔好誤會）：系統啱啱建立，最近一日嘅 K 會特別「粗」— 因為平台淨係提供最近 ~20 筆成交嘅窗口，首次全量爬取等於一次過吸咗幾十日嘅成交入同一日。聽日開始，每日新增嘅 K 就係真正嘅「日線」：邊日有成交、幾多錢、幾多筆，一目瞭然。歷史部分會隨每日累積越補越長。

### 3.3 點樣配合用

1. `summary.json` 睇排行榜 → 搵到異動卡
2. `card_metrics.csv` 睇嗰卡嘅量同序列樣本數 → 判斷異動可唔可信
3. `klines/*.csv` 睇價格結構 → 係突破、回調定單日噪音
4. `cards/*/summary_en.json` 睇 AI 報告 + `populations.json` 睇稀缺度 → 基本因素支唔支持

## 4. 點樣講（對外口徑）

講呢套嘢嘅時候，重點係**數據整合同分析方法**，唔係「爬咗邊個」。標準講法：

| 場合 | 講法 |
|------|------|
| 一句講晒 | 「我建咗個收藏卡市場數據庫，每日自動同步兩大交易平台嘅成交，自己計指標同 K 線。」 |
| 人問數據邊嚟 | 「公開市場數據 — Snkrdunk 同 eBay 嘅成交記錄，經 Grade10 嘅公開指數服務整合。」 |
| 人問同 Grade10 咩關係 | 「佢哋係數據來源之一；分析層（升跌指標、成交量、K 線）係我自己建嘅。」 |
| 講成交量 | 「呢個係兩平台嘅可觀測成交，唔係全市場 — 但係趨勢同相對排名好有參考價值。」 |
| 講升跌% | 「用同一鑑定等級嘅價格序列計，避免混入唔同等級造成嘅假升跌。」（呢句係你嘅專業護城河） |

**講嘅時候三個唔好**：
- 唔好講「逆向」「破解」「攞咗佢 API」— 事實上全部係公開接口，但啲字难听落似攻擊
- 唔好將單日 K 線嘅 open/close 當逐筆成交順序講（同日內嘅先後次序係聚合出嚟嘅）
- 唔好將 30 日升跌% 用喺樣本少嘅卡上面 — 直接講「呢隻成交疏，參考價值有限」仲顯專業

## 5. 已知限制（自己要知道）

1. **成交歷史深度係累積緊嘅**：平台窗口得 ~20 筆，你嘅 `sales_cache` 由 2026-07-22 開始每日累積。一個月後先有完整 30 日逐日成交。
2. **1d 升跌% 暫時覆蓋率低**（287/600）：需要兩日嘅平台日平均價先計到，聽日第二次跑完會升到 ~465。
3. **PSA 10 以外嘅等級**：K 線同升跌% 默認 PSA 10（市場標準）。要其他等級可以跑 `python grade10_kline.py --grade "PSA 9"`。
4. **eBay 成交有混入裸卡嘅噪音**：已用價格過濾處理（低於等級均價 25% 歸入 Ungraded），但極端個案可能存在。
5. **指數歷史係完整嘅**（2023-02 至今），呢部分冇限制。
